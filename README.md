# phonix-site

The public pages the App Store needs for Phonix (the PhonicsGame iOS app), served by GitHub Pages from `main`:

- Privacy policy: https://jameshemson.github.io/phonix-site/privacy.html
- Support: https://jameshemson.github.io/phonix-site/support.html

Both URLs are set in App Store Connect. `privacy.html` is also kept in the PhonicsGame repo as `docs/privacy-policy.html`; change both together.
